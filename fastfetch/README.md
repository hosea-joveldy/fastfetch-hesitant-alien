# Hesitant Alien fastfetch config
My personal [fastfetch](https://github.com/fastfetch-cli/fastfetch) config based on the album "Hesitant Alien" by Gerard Way.

## Contents
- **config.jsonc** = The config file for fastfetch.
- **ascii.txt** = File for the ascii art (i also colored the ascii manually).

## Requirements
 1. **fastfetch**: Visit the official [repo](https://github.com/fastfetch-cli/fastfetch#installation) to install fastfetch, i ain't explaning it.

 ## How to use this repo
### Clone the repo:
```bash
git clone https://github.com/hosea-joveldy/fastfetch-hesitant-alien.git
```

### Verify directory:
Make sure the project folder is inside **.config** folder:

1. In Windows you can usually find it in:
>C:\Users\[whatever your username is]\.config\[folder here]

    Note: If the folder doesn't exist then create it,
    it's best practice to set the folder to hidden.

2. Linux:
>/home/[your username]/.config/[folder here]

### Modify the config file:
1. Open **config.jsonc** in any text editor.
2. Change the directory inside **source** prop to the ascii.txt in your machine.
